# Mekanism Energistics Unofficial Deconstructed

Mekanism gases for [AE2 Unofficial Deconstructed](https://github.com/romanfedyniak/AE2UD), for Minecraft 1.12.2.

This is a fork of [Mekanism Energistics](https://github.com/AE2-UEL/MekanismEnergistics) by GlodBlock,
KasumiNova, atlas2832 and zeng-github01, rewritten to fit AE2UD.

Where the original added a gas copy of nearly every AE2 part - a gas terminal, gas buses, a gas storage bus,
a gas interface - AE2UD has one of each that works with any kind of content. So this mod registers gas as a
key type, and the parts that are already there carry it: the terminal lists gases, an import bus pulls them,
a storage bus mounts a gas tank, an interface stocks them, a pattern may hold them. What it adds of its own
is what has no counterpart: gas cells, portable gas cells and a gas P2P tunnel.

Mekanism, Mekanism CE and Mekanism CEu are all supported. Builds are made against Mekanism CE.

## Compatibility

- This mod runs only with AE2 Unofficial Deconstructed, not with standard AE2 or AE2 Unofficial Extended Life.
- A world that used the original Mekanism Energistics on AE2 UEL is not carried over yet; AE2UD itself does
  not read AE2 UEL worlds.
- Back up the world before installing or updating.
